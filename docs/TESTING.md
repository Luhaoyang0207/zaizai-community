# Manual test checklist

Needs a real test Discord server and a separate test bot token; cannot be automated.

## 语音房间 (voice rooms)

- [ ] 进入入口房间 -> 机器人建房并把你移入，你是房主；面板由 panel 模块发出（需 panel 模块启用）
- [ ] 房间名按该模式的 name_template 取最小未用编号
- [ ] 分类满 45（`voice.category_max_channels`）-> 自动新开分类（名称为原分类名 + " 2"，权限复制），房间建在新分类
- [ ] 房间空 30 秒后被删除，总表条目立即消失（`board.remove_when_room_empty`）
- [ ] 房间变空后 30 秒内重新进入 -> 房间不被删
- [ ] 进入入口后立刻离开 -> 新建的房间被删除，不留空房间
- [ ] 重启机器人后对账：分类里建一个未登记的空房间 -> 被删；有人的未登记房间 -> 被认领（房主为房内第一人）；记事本里有但服务器已没有的房间 -> 记录被清掉
- [ ] 重启后所有模式的总表立即刷新一次
- [ ] 新建房间的权限与所在分类一致（私有分类里的房间不会变成公开）
- [ ] 缺少"移动成员"权限时：管理频道收到一次提示，且不会残留空房间

注意：受管分类必须专用于机器人；其中任何其他空的语音频道会在重启对账时被删除。

## 组队命令 (LFG command)

- [ ] 三种打法都能出卡片：`!pw 铂钻 3=2`、`！pw 铂钻 3=2`、`! pw 铂钻 3=2`
- [ ] 卡片发在玩家消息下方（回复），标题是需求文字，含总表频道链接、发起人和时间
- [ ] 不在临时语音房间时发命令 -> 收到 `commands.need_voice_msg` 提示，没有卡片、没有条目
- [ ] 在自己语音房间的内置文字聊天里发命令 -> 同样出卡片（`commands.allow_in_room_chat=true`）
- [ ] 命令和频道/房间模式不匹配（如在匹配频道发 `!pw`）-> 无反应
- [ ] 同一房间重复发命令 -> 总表里只有一条，内容为最新需求
- [ ] `!pw` 后不带文字 -> 卡片标题为"组队中"
- [ ] `card.delete_original` 为真 -> 卡片发出后原消息被删；为假 -> 原消息保留
- [ ] 缺少"管理消息"权限时删除原消息 -> 管理频道收到一次提示，卡片仍在
- [ ] 机器人发的消息和私信里的 `!pw` 被忽略
