# Manual test checklist

Needs a real test Discord server and a separate test bot token; cannot be automated.

## 语音房间 (voice rooms)

- [ ] 进入入口房间 -> 机器人建房并把你移入，你是房主；面板由 panel 模块发出（需 panel 模块启用）
- [ ] 房间名按该模式的 name_template 取最小未用编号
- [ ] 分类满 45（`voice.category_max_channels`）-> 自动新开分类（名称为原分类名 + " 2"，权限复制），房间建在新分类
- [ ] 房间空 30 秒后被删除，总表条目立即消失（`board.remove_when_room_empty`）
- [ ] 房间变空后 30 秒内重新进入 -> 房间不被删
- [ ] 进入入口后立刻离开 -> 新建的房间被删除，不留空房间
- [ ] 重启机器人后对账：分类里建一个未登记的空房间 -> 被删；有人的未登记房间 -> 被认领（房主为房内第一人）；记事本里有但服务器已没有的房间 -> 记录被清掉
- [ ] 重启后所有模式的总表立即刷新一次
- [ ] 新建房间的权限与所在分类一致（私有分类里的房间不会变成公开）
- [ ] 缺少"移动成员"权限时：管理频道收到一次提示，且不会残留空房间

注意：受管分类必须专用于机器人；其中任何其他空的语音频道会在重启对账时被删除。

## 组队命令 (LFG command)

- [ ] 三种打法都能出卡片：`!pw 铂钻 3=2`、`！pw 铂钻 3=2`、`! pw 铂钻 3=2`
- [ ] 卡片发在玩家消息下方（回复），标题是需求文字，含总表频道链接、发起人和时间
- [ ] 不在临时语音房间时发命令 -> 收到 `commands.need_voice_msg` 提示，没有卡片、没有条目
- [ ] 在自己语音房间的内置文字聊天里发命令 -> 同样出卡片（`commands.allow_in_room_chat=true`）
- [ ] 命令和频道/房间模式不匹配（如在匹配频道发 `!pw`）-> 无反应
- [ ] 同一房间重复发命令 -> 总表里只有一条，内容为最新需求
- [ ] `!pw` 后不带文字 -> 卡片标题为"组队中"
- [ ] `card.delete_original` 为真 -> 卡片发出后原消息被删；为假 -> 原消息保留
- [ ] 缺少"管理消息"权限时删除原消息 -> 管理频道收到一次提示，卡片仍在
- [ ] 机器人发的消息和私信里的 `!pw` 被忽略

状态：未在测试服务器验证。

## 总表 (live board)

- [ ] 发命令后，总表频道中对应模式的消息出现该条目（需求、发起人、时间、"查看卡片"链接、右侧"{人数}人 @ {房间名}"按钮）
- [ ] 点"查看卡片"跳到卡片；点房间按钮跳到语音房间
- [ ] 有人进出房间后 5 秒内（`board.refresh_debounce_sec`）按钮上的人数更新
- [ ] 房间空了 -> 条目消失；没有条目时显示 `board.empty_text`
- [ ] 手动删掉总表消息 -> 下次刷新自动重发，不留重复消息
- [ ] 手动删掉卡片 -> 机器人不报错
- [ ] 条目超过每页上限（可临时把 `board.max_entries_per_message` 调成 2）-> 自动分页，标题显示 "i/n"；条目变少后多余的分页消息被删
- [ ] 30 分钟超时（可临时把 `board.entry_timeout_min` 调成 1）-> 约 1~2 分钟内条目被清掉，卡片保留
- [ ] 总表消息不提醒任何人（需求里写 @everyone 也不提醒）
- [ ] 重启机器人后总表原地刷新，不重复发消息
- [ ] 命令为空的模式（默认 `commands.other = ""`）不发总表
- [ ] 手动删掉某个临时语音房间 -> 1 分钟内（清理任务）该条目消失
- [ ] 需求里写 `# 标题`、`**粗体**` 或换行 -> 总表里按原文单行显示，不变成标题/粗体

状态：未在测试服务器验证。

## 面板 (room panel)

- [ ] 建房后房间内置聊天里出现面板：@房主（只提醒房主一次）+ `panel.help_text` + 🔓开、组队已满 两个按钮
- [ ] 非房主点任一按钮 -> 收到仅自己可见的"只有房主可以使用面板"，无其他变化
- [ ] 房主点 🔓开 -> 按钮变 🔒锁；另一账号进不来；已在房间里的人不受影响；房主离开后仍能重新进入
- [ ] 再点 🔒锁 -> 按钮变 🔓开；另一账号能进
- [ ] 私有分类里的房间锁/解锁后仍不对外可见（只改 connect 权限，不覆盖其他权限）
- [ ] 有组队信息时房主点"组队已满" -> 总表条目消失，卡片保留；再点 -> 提示"当前没有组队信息"
- [ ] 重启机器人后按钮仍可点（锁/解锁、组队已满都有效）
- [ ] 面板被手动删后，在房间聊天里 `/panel` 能重发（旧面板如还在会被删掉）；不在该语音房间的人用 `/panel` 被拒
- [ ] 在非临时房间的频道用 `/panel` -> 提示"只能在临时房间的聊天里使用"
- [ ] 房间已被删除后点旧面板按钮 -> 提示"房间已不存在"（不显示"应用未响应"）
- [ ] 机器人缺少"管理权限"时点锁 -> 用户收到失败提示，管理频道收到一次权限提示
- [ ] `panel.enabled=false` -> 建房不发面板，`/panel` 提示"面板功能已关闭"

状态：未在测试服务器验证。

## 管理指令 (admin commands)

- [ ] `/motto 文字` -> 仅自己可见的确认；下一张卡片页脚立即变成该文字；`/motto clear` 后页脚消失（即使配置里有默认页脚）
- [ ] `/ad 文字` -> 下一张卡片出现广告位文字；`/ad clear` 后广告消失；`card.ad_enabled=false` 时即使设了文字也不显示
- [ ] `/setting delete_original on` -> 之后发组队信息，原消息被删；`off` 后不删
- [ ] `/setting delete_original on 频道:#某频道` 只对该频道生效，且优先于全局设置
- [ ] 文字超长（页脚 > 2048、广告 > 1024）-> 提示太长，设置不变
- [ ] 重启机器人后以上设置仍保留
- [ ] 没有"管理服务器"权限的账号：指令在列表里不可见/被拒，提示"需要「管理服务器」权限"（不显示"应用未响应"），日志里不记 error

状态：未在测试服务器验证。
